# MAGANGTRACK

Smart Internship Management & Monitoring System

Sistem informasi berbasis website untuk membantu mahasiswa
mengelola proses pendaftaran, pelaksanaan, dan monitoring magang.

## Teknologi
- HTML, CSS, JavaScript
- PHP Native
- MySQL
- Laragon

## Fitur Utama
- Explore Internship
- Application Tracker
- Document Checklist
- My Internship
- Digital Logbook
- Calendar & Deadlines
- Monitoring Dosen Pembimbing

In Development
